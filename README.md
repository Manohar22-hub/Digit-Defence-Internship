## 🚀 Projects

### 1️⃣ Nmap – Network Scanning & Security Auditing

A practical network security project focused on using **Nmap (Network Mapper)** for network discovery, port scanning, service and version detection, OS fingerprinting, and vulnerability assessment.

**Key activities:**

* Host discovery
* Port scanning
* Service and version detection
* Operating system detection
* Aggressive scanning
* Nmap Scripting Engine (NSE) vulnerability assessment
* Vulnerability identification
* Risk analysis and mitigation recommendations

**Environment:**

`Kali Linux → Nmap → Metasploitable 2`

📁 **Project folder:** `Project-1-Nmap/`

---

### 2️⃣ Wireshark – Network Traffic Analysis & Packet Sniffing

A practical network security project focused on capturing and analyzing network traffic using **Wireshark**.

**Key activities:**

* Network packet capture
* ICMP traffic analysis
* ARP packet analysis
* TCP traffic analysis
* HTTP traffic analysis
* Protocol identification
* Packet filtering
* Examination of source and destination information
* Analysis of HTTP requests and responses
* Security analysis of captured traffic

**Environment:**

`Kali Linux → Wireshark → Controlled Lab Network`

📁 **Project folder:** `Project-2-Wireshark/`
